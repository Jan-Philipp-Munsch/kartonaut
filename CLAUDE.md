# Hinweise für Claude

## README aktuell halten

`README.md` (Englisch) und `README.de.md` (Deutsch) sind die Startseite auf GitHub und sollen immer den
echten Projektstand zeigen. Jan möchte, dass sie mitgepflegt werden, ohne dass er danach fragt.

- Wer den Projektstand ändert (Merge nach `main`, neuer PR, Entscheidung, gebautes oder bestelltes Teil,
  neue Messwerte, geänderte Masse, neuer Versuch), zieht im selben Branch beide READMEs nach: „Auf einen
  Blick“, „Projektstand“ (Erledigt / Wartet auf Review und Merge / Als Nächstes) und die betroffenen
  Abschnitte, dazu die Zeile `Stand:` / `Last updated:` mit dem Datum.
- Beide Fassungen inhaltlich gleich halten.
- Nur auf Dateien verlinken, die im selben Branch liegen; Arbeit, die noch auf einem anderen Branch
  liegt, über den PR oder den Branch auf GitHub verlinken.
- Zahlen (Masse, Schwerpunkt, Gipfelhöhe, Tests) aus der jeweils neuesten Quelle nehmen, nicht aus
  älteren Abschnitten abschreiben.
